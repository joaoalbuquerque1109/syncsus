# Prévias dos documentos médicos

Estas prévias foram geradas em 29/07/2026 com:

- o template Blade atual de documentos clínicos;
- o renderizador PDF atual do SYNC SUS;
- a identidade visual e os dados demonstrativos presentes no SQLite local;
- conteúdos clínicos inteiramente fictícios.

Cada documento possui uma imagem PNG para visualização e um PDF correspondente. As prévias não foram inseridas como documentos clínicos no banco de dados.

Arquivos disponíveis:

1. atestado médico;
2. declaração de comparecimento;
3. declaração de acompanhante;
4. receita;
5. solicitação de exames;
6. encaminhamento;
7. relatório médico;
8. orientações de alta;
9. resumo do atendimento.
